# rexgalley

Features of this Photo Gallery Application:

    Instagram-like Interface:

        Clean, modern design with a profile section

        Grid layout for photos

        Navigation tabs (Posts, About, Reels)

    Photo Upload Functionality:

        Drag & drop or click to upload

        Preview of selected image

        Upload button to add to gallery

    Photo Management:

        Delete photos with confirmation modal

        Hover effects on gallery items

    Responsive Design:

        Works on mobile, tablet, and desktop

        Adjusts layout based on screen size

    Profile Section:

        Profile picture

        User stats (posts, followers, following)

        Bio information
